# Carrefour Kenya – Black November Deals Analysis

## Project Overview

This project explores Black November deals at Carrefour Kenya using Python and data visualisation.

The objective is to identify departments offering attractive discounts, understand discount distributions and compare product prices.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Product price analysis
- Discount percentage analysis
- Product distribution by department
- Price comparisons
- Correlation analysis
- Heatmaps and scatter plots
- Department-level discount comparisons

## Final Visual Report

The project includes a visual report containing:

1. Average discounts by department
2. Distribution of discount percentages
3. Discount comparisons by department
4. Share of discounted products by department

![Carrefour Black November Report](carrefour_black_november_report.png)

## Key Objective

To investigate where the best Black November deals are at Carrefour Kenya through exploratory data analysis and visualisation.
